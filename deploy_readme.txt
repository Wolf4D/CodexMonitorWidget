A lightweight Cyber-HUD desktop status monitor for Codex CLI & Desktop
on Windows.

QUICK START:
------------
1. Double-click "run.bat" or "codex_widget.exe" to launch the widget.
2. The widget will appear on your desktop and in the Windows System Tray.
3. Start using Codex CLI or Codex Desktop as usual — CMW will monitor
   your session, rate limits, and command execution in real time!

KEY CONTROLS:
-------------
- Move Widget:         Click and drag anywhere on the header or body.
- Pin (Stay on Top):   Click the pin icon [📌] in the top right.
- Compact Mode:        Click [▲] / [▼] in the top right.
- Expand Reply:        Click the [💬] toggle button on the assistant card.
- Copy Message / Cmd:  Click the [📋] button inside each respective card.
- System Tray:         Right-click the tray icon to switch language (EN/RU),
                       toggle pin, reset window position, or exit.

PRIVACY & SECURITY GUARANTEE:
-----------------------------
- No internet access: Never connects to remote servers or sends telemetry.
- No tokens or credentials: Does not require or store API keys or passwords.
- No data interception: Does not log, capture, or transmit your code or chats.
- 100% local passive monitoring on your computer.

SYSTEM REQUIREMENTS:
--------------------
- Windows 10 or Windows 11 (64-bit or 32-bit).
- No installation or runtime dependencies needed (fully standalone).
